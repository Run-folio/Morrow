# Read-only Today implementation plan

**Goal:** Implement approved desktop/mobile Today references on staging f1fc1c5 without changing canonical trip data.

**Architecture:** Pure Today projection over existing itinerary composition, stay presentation and transport agenda. A client clock refreshes on visibility/minute boundaries. IANA country timezone identifiers resolve only unambiguous country or exact country/city matches; unknown or ambiguous dates offer an explicitly labelled day preview. No device-date fallback, tracking, completion model or second itinerary store.

**Spec:** libfile_be67e3c6ba348191b172f394bf51df85 and libfile_acae4056c3188191ab5e94d823acdb26; bounded read-only view, lean copy, staging only.
